# AGAPEDIA
Digital Learning Portal — SD Kristen Agape Terpadu Nabire

## Struktur
- `index.html` — halaman utama
- `style.css` — desain responsive
- `script.js` — menu mobile, animasi, dan placeholder link
- `assets/favicon.svg` — favicon

## Deploy gratis ke GitHub Pages
1. Buat akun GitHub jika belum punya.
2. Buat repository baru. Untuk alamat `username.github.io`, nama repository harus `username.github.io`.
3. Upload semua isi folder ini ke repository.
4. Buka Settings → Pages.
5. Pilih Source: Deploy from a branch → branch `main` → folder `/ (root)` → Save.
6. GitHub akan memberikan alamat website `https://username.github.io/`.

Catatan: semua tombol portal yang masih `#` sengaja dibuat sebagai placeholder. Link sebenarnya akan dimasukkan setelah struktur AGAPEDIA disetujui.
